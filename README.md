# Astrocade — Astro World

Game sandbox "god sim" ala WorldBox, satu file HTML5 Canvas (`index.html`), tanpa dependensi.
Buka `index.html` di browser (desktop atau HP).

## Fitur
- Dunia prosedural (laut, pasir, rumput, hutan, bukit, gunung, salju) yang dibuat acak setiap kali.
- **Medan**: naikkan/turunkan tanah, cat rumput, hutan, pasir, lava.
- **Makhluk**: manusia, elf, kurcaci, orc, domba, serigala. Mereka berjalan sendiri, membangun rumah, berkembang biak, berburu, dan berperang.
- **Kekuatan**: hujan, api (menyebar lewat hutan dan rumah), petir, meteor, berkati, bunuh, periksa.
- Siklus siang-malam, kecepatan 1×/3×/8×, jeda, dan ukuran kuas.

## Kontrol
- Seret = pakai alat. Klik kanan / spasi + seret / tombol ✋ = geser peta.
- Zoom pakai tombol + / − (mentok di full map). `P` = jeda. `[` dan `]` = ukuran kuas.
